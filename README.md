# uv tutorial

このディレクトリでは、`uv` を使った Python プロジェクト管理を 3 段階で学びます。

- `step_1`: `uv sync` で既存プロジェクトの環境を復元して、そのまま実行する
- `step_2`: `uv sync` で復元した後、足りないライブラリを追加して実行する
- `step_3`: `uv init` で新規プロジェクトを作って、依存関係を追加し、実行する

## Step 1

`step_1` は、`pyproject.toml` と `uv.lock` が揃っている状態から環境を復元するチュートリアルです。

### 学ぶこと

- `uv sync` を使うと、ロックファイルに基づいて仮想環境を再現できる
- 依存関係が揃っていれば、そのまま `uv run` で実行できる

### やること

- `step_1` に移動する
- `uv sync` を使って環境を復元する
- 復元した環境で `main.py` を実行する

## Step 2

`step_2` は、`uv sync` でいったん環境を復元したあと、実行に必要なライブラリが不足しているケースを扱います。

### 学ぶこと

- `uv sync` は `pyproject.toml` と `uv.lock` に書かれた依存だけを復元する
- 実装に対して依存が足りなければ、`uv add` で追加してから実行する

### やること

- `step_2` に移動する
- `uv sync` でいったん環境を復元する
- 実行時に不足するライブラリを確認する
- 足りない依存関係を追加する
- 追加後に `main.py` を実行する

## Step 3

`step_3` は、まだプロジェクトがない状態から `uv init` で開始し、依存関係を追加して実行するチュートリアルです。

### 学ぶこと

- `uv init` で新しい Python プロジェクトを作成できる
- `uv add` で必要なライブラリを追加できる
- `uv run` で仮想環境を意識せずにスクリプトを実行できる

### やること

- 新しい Python プロジェクトを `uv init` で作成する
- 実行に必要な依存関係を追加する
- `main.py` を用意する
- `uv run` で実行する

## 進め方

おすすめの順番は `step_1` → `step_2` → `step_3` です。

- `step_1` で「復元」の基本を確認する
- `step_2` で「依存追加」の流れを確認する
- `step_3` で「新規作成から実行まで」を一通り行う
